# IKEv2-PSK-Windows11
IKEv2/IPsec PSK VPN client for Windows 11 — version 0.5

## معرفی برنامه (نسخه ۰٫۵)

این برنامه برای اتصال مستقیم به سرورهای VPN با پروتکل IKEv2/IPsec و کلید مشترک (PSK) در ویندوز ۱۱ نسخه ۶۴ بیتی طراحی شده است. برای استفاده با سرورهای MikroTik نیز تنظیمات سازگار در نظر گرفته شده است.

### امکانات
- اتصال با IKEv2/IPsec PSK بدون نیاز به کلاینت داخلی ویندوز؛
- چهار فیلد قابل ویرایش: آدرس IP سرور، شناسه IPsec، کلید مشترک و شناسه اختیاری سرور (Remote ID)؛
- تنظیمات پیشرفته و الگوریتم‌های مذاکره به‌صورت پیش‌فرض خودکار؛
- نمایش مجموع حجم دانلود و آپلود هر جلسه؛
- مسیریابی IPv4 از تونل و محافظت آزمایشی در برابر نشت DNS و IPv6؛
- قطع اضطراری اینترنت (Kill Switch) هنگام اختلال در تونل؛
- ذخیره نکردن کلید مشترک در تنظیمات برنامه.

### روش اجرا
1. پس از انتشار، فایل `IKEv2-PSK-Windows11-v0.5.zip` را از بخش [Releases](../../releases) دریافت و به‌طور کامل Extract کنید.
2. نسخه قبلی را در صورت اتصال، Disconnect کرده و ببندید.
3. فایل `IKEv2-PSK-Client.exe` را با گزینه **Run as administrator** اجرا کنید. فایل `wintun.dll` باید در کنار آن باقی بماند.
4. آدرس IPv4 سرور، شناسه IPsec و کلید مشترک را وارد کنید. اگر شناسه واقعی سرور را می‌دانید، Remote ID را مطابق آن وارد کنید؛ در غیر این صورت می‌توانید آن را خالی بگذارید (احراز هویت PSK همچنان انجام می‌شود، اما شناسه سرور جداگانه بررسی نمی‌شود).
5. روی **Connect** بزنید و منتظر وضعیت **Connected** بمانید.
6. برای بررسی IP خروجی و نشت DNS/IPv6، تست‌های فایل `TEST-LEAKS-FA.txt` را انجام دهید.
7. برای پایان اتصال از **Disconnect** استفاده کنید.

### محافظت در برابر نشت ترافیک
در نسخه ۰٫۵ از فیلترهای موقت Windows Filtering Platform (WFP) استفاده شده است. اگر نصب فیلترها ناموفق باشد، برنامه اتصال را آغاز نمی‌کند. در قطع ناخواسته تونل، محافظت تا انتخاب Restore internet فعال می‌ماند. IPv6 به‌جای تونل شدن مسدود می‌شود و DNS باید از تونل عبور کند. ممکن است سایر VPNها و دسترسی شبکه محلی محدود شوند.

**محدودیت مهم:** در خروج عادی، بسته شدن اجباری برنامه، Crash یا راه‌اندازی مجدد سیستم، فیلترهای موقت حذف می‌شوند. این Kill Switch دائمی نیست. فایل اجرایی ساخته شده و تست‌های داخلی انجام شده‌اند، اما عملکرد واقعی فیلترهای Windows و عدم نشت مطلق مستقل از محیط هنوز تأیید نشده است.

### رفع خطاهای رایج
- **AUTHENTICATION_FAILED (24):** کلید مشترک و شناسه IPsec را با تنظیمات سرور مقایسه کنید.
- **NO_PROPOSAL_CHOSEN (14):** الگوریتم‌های رمزنگاری، تنظیمات Profile/Proposal و DH/PFS سرور را بررسی کنید.
- **Responder ID differs:** شناسه واقعی سرور را وارد کنید یا در صورت پذیرش محدودیت احراز هویت شناسه، Remote ID را خالی بگذارید.
